# 决策规则速查 — 以日为鉴：衰退时代生存指南

| 能力 | 一句话规则 |
|---|---|
| 岗位质量与职业积累 | 把组织存续、雇佣身份、实际训练和未来可迁移性分开判断。 |
| 升学与目标岗位匹配 | 先验证目标岗位为何需要这段训练，再判断继续升学，而不是只预测毕业时经济会转好。 |
| 留城、返乡与岗位需求持续性 | 同时核实岗位靠谁付费、需求能持续多久、拥挤程度以及退出后的去处。 |
| 稳定职业的条件审查 | 稳定是由具体用工、财政和工作条件形成的状态，不是职业名称附带的永久属性。 |
| 人口变化与教师岗位结构 | 沿学龄人口、学校布局、财政与用工结构逐层判断，而不是从出生人数直接跳到个人失业结论。 |
| 医疗需求、支付约束与岗位激励 | 把服务需求、付款能力、支付规则和收益归属分开，识别哪一环把需求增长转成压力。 |
| 行业增长到个人收益的传导检查 | 沿利润来源、产能所在地、所需技能和雇佣安排追踪收益，不能把行业增长直接当成个人成长。 |
| 出海阶段与本土化能力匹配 | 识别企业所处阶段和你能解决的当地问题，避免把出海标签、龙头名气或固定年份当机会本身。 |
| 历史经验迁移前提检查 | 把历史故事拆成条件、机制和结果，再检验条件是否成立；相似现象只提供假设。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
